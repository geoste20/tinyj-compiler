# TinyJ Compiler

A compiler for TinyJ, a subset of Java, developed through a three-part compiler construction project at Queens College (CUNY).

## Overview

TinyJ is a small subset of Java used for studying compiler construction. This project implements the major stages of a compiler, including syntax analysis, semantic analysis, and code generation.

## Project Structure

### Part 1 - Syntax Analysis
- Recursive descent parser
- Parse tree generation
- Grammar validation using EBNF rules

### Part 2 - Semantic Analysis
- Symbol table management
- Scope checking
- Semantic validation

### Part 3 - Code Generation
- Translation of TinyJ programs into virtual machine code
- Program execution support

## Technologies

- Java

## Concepts Demonstrated

- Context-Free Grammars
